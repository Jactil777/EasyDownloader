# EasyDownloader

一个仅在 Windows 本机运行的媒体下载工具。浏览器负责交互，本地 Node.js 进程调用 yt-dlp、gallery-dl 和 FFmpeg 完成解析与下载。

## 首次使用

1. 确保已安装 Node.js 20 或更高版本。
2. 右键 `install-tools.ps1`，选择“使用 PowerShell 运行”。脚本会安装常用解析器, 并额外准备微信视频号解析组件 (需联网, 不需要管理员权限)。
3. 双击 `start.cmd`。
4. 浏览器会自动打开 `http://127.0.0.1:8765`。

如果 PowerShell 阻止脚本运行，可在项目目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\install-tools.ps1
```

## 功能

- 每次粘贴最多 10 个链接；
- 自动识别视频、图片及其他素材链接；
- 需要登录的网站可导入浏览器扩展导出的 Netscape 格式 `cookies.txt`；
- 微信视频号链接可直接粘贴; 首次使用会打开独立的腾讯元宝登录窗口, 成功后自动下载到当前保存目录；
- 实时任务进度、失败信息和取消；
- 文件直接保存到本机目录；
- 不使用自建服务器、数据库或云端存储。

## 注意事项

- 解析能力取决于 yt-dlp 和 gallery-dl，网站更新后可能需要更新工具版本。
- `cookies.txt` 是网站登录凭证, 请勿分享或上传到不可信位置。
- 微信视频号解析会将分享链接发送给腾讯元宝, 元宝登录凭据保存在当前 Windows 用户的本地应用数据目录, 不读取 Chrome 日常登录 Cookie。元宝接口为非公开接口, 变更后可能暂时不可用。
- 微信视频号解析组件由 `install-tools.ps1` 安装到项目 `tools` 目录; 安装需要网络, 首次登录时需在弹出的元宝窗口完成验证。
- 请只下载你有权保存的公开内容，不支持 DRM 或付费内容的绕过。
