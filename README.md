# EasyDownloader

EasyDownloader 是 Windows 桌面媒体下载客户端。客户端在后台启动本地服务并显示应用窗口，不会弹出命令行窗口。常规解析和下载在用户电脑上进行，应用不使用自建下载服务器、数据库或云端文件存储。

## 安装与使用

运行 GitHub Releases 中的 `EasyDownloader-Setup-<版本>.exe`，按安装程序提示完成安装。安装后可从桌面快捷方式或开始菜单启动；无需另装 Node.js，也无需手动运行脚本。升级安装不需要先卸载旧版本。

在“素材链接”区域每行粘贴一个链接（最多 10 个），点击“开始下载”。需要登录的网站，可以先在浏览器登录并导出 Netscape 格式 `cookies.txt`，再通过“选择 cookies.txt”导入。Cookie 文件等同登录凭证，请勿分享。

下载任务、进度和最近 200 条记录会保存在本机。清空下载记录只删除任务历史，不会删除已下载文件。关闭客户端窗口会停止本地服务。

## 微信视频号

视频号分享链接可直接粘贴，客户端会自动调用内置的视频号解析组件，不需要手动复制媒体地址。首次使用时会打开腾讯元宝登录窗口，请完成登录/验证后等待下载；后续通常可复用本机保存的登录状态。元宝登录凭据保存在当前 Windows 用户的应用数据目录，不使用 Chrome 日常 Cookie。

视频号分享链接会发送给腾讯元宝进行解析。元宝相关接口并非公开稳定接口，登录状态、内容可见性或上游变化都可能导致个别内容解析失败，因此不能保证所有视频号链接均可下载。客户端只处理解析获得的资源，不绕过付费、DRM 或平台权限限制。请仅保存你有权使用的内容。

## 客户端自动更新

安装版启动时会检查公开 GitHub Releases。发现新版本后，顶部会出现更新按钮；点击下载，完成后点击“重启并完成更新”，客户端将退出、安装并重新启动。版本 `0.1.0` 不含更新模块，需先手动运行一次 `0.1.1` 或更新版本安装包；此后的版本可从客户端更新。更新只会检测已经正式发布的 Release。

发布版本时，先同步递增 `package.json` 和 `package-lock.json` 的版本号并推送代码，再推送对应标签（例如 `v0.1.2`）。GitHub Actions 会构建 Windows 安装包并发布 Release 与自动更新元数据。仓库工作流已配置 `contents: write` 权限。

## 开发与打包

开发运行可执行 `start.cmd`，或运行 `npm run desktop` 启动桌面客户端。在 Windows 开发机上安装 Node.js 20 或更新版本，然后运行：

```powershell
npm install
npm run build:installer
```

`build-installer.ps1` 会准备 Windows Node.js 运行时，并在缺少依赖工具时安装 yt-dlp、gallery-dl、FFmpeg 和视频号解析组件，然后检查源码并生成 `release/EasyDownloader-Setup-<版本>.exe`。日常只修改项目代码后，重新运行 `npm run build:installer` 即可快速打包；需要同步上游解析工具时运行 `npm run build:installer -- -UpdateTools`。打包和下载工具需要网络。

## 支持范围与隐私

- 视频、图片和其他素材解析依赖 yt-dlp、gallery-dl 及站点自身接口；网站更新可能暂时影响支持情况。
- 微信视频号分享链接会发送给腾讯元宝解析；其他站点的下载由本机解析工具处理。
- 下载文件、Cookie 文件、任务历史和视频号登录状态保存在本机；应用不会把这些数据上传到 EasyDownloader 服务器。
- `cookies.txt` 是敏感凭证，只从可信来源导入，使用完后妥善保管或删除。
- 请遵守内容来源网站的服务条款、版权和当地法律，不要下载或传播无权使用的内容。
